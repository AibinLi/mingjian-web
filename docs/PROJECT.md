# 项目定义

> **Historical / legacy project record:** 本文件保留项目范围演进记录。当前能力状态与运行边界请以 [CURRENT_STATUS.md](CURRENT_STATUS.md) 为准；当前架构请以 [ARCHITECTURE.md](ARCHITECTURE.md) 为准。

## 一句话定义

明鉴 Web 是面向社交媒体图片、音频和视频的防御性风险研判 Web 平台：分别分析媒体真实性、内容可信度和来源可靠性，并展示可追溯证据与限制，而非给出武断的单一真伪标签。

## 当前阶段与已交付

阶段 2 已完成真实 FFmpeg 媒体闭环验收。当前可运行交付在阶段 1 Mock 工作流上增加了安全、可追溯的本地媒体预处理；仍不依赖真实模型，三轴报告仍是明确 `mock=true` 的独立占位报告。

## 当前范围

- 仅 Web 产品形态。
- 受限文件上传、服务端 SHA-256/对象键、SQLite 任务持久化与本地 Mock Worker。
- URL 仅作为受限引用保存，不访问、不下载、不抓取。
- 三轴独立建模、存储、展示和测试：媒体真实性、内容可信度、来源可靠性。
- 对本地文件执行魔数/MIME/容器校验、受限 FFmpeg/FFprobe 预处理、标准化派生物、镜头/关键帧索引和本地 Mock 适配器输出。

## 当前非范围

- 任何真实人脸检测/跟踪、VAD、ASR、OCR 或深伪检测模型、模型指标或实验结果。
- URL 抓取、联网检索、真实事实核查、来源溯源和真实模型报告。
- 用户鉴权、租户隔离、生产队列、生产对象存储、部署业务。
- 浏览器插件、移动端、Codex/Agent Skill、系统级抓流和司法鉴定结论。

## 三轴结论模型

| 轴 | 回答的问题 | 不可替代关系 |
| --- | --- | --- |
| 媒体真实性 | 文件是否存在 AI 生成或篡改迹象？ | 不等于内容为假。 |
| 内容可信度 | 可验证主张是否被可靠证据支持？ | 不等于媒体被篡改。 |
| 来源可靠性 | 出处与传播链是否可信？ | 不等于文件真伪或主张真伪。 |

系统必须允许“不确定/无法判断/暂无充分证据”。阶段 1 的三个轴均是 `mock=true` 的“无法判断”占位结果，绝不表示真实分析。

## 真实性与竞赛约束

项目只提供防御性能力。所有功能、测试与指标均需有实际证据；建议目标不得描述为取得结果。不得下载未经授权的模型，不得伪造分析，不得规避 DRM、登录或访问限制，不得提交用户媒体、个人信息或密钥。
