# 已知限制

本文集中记录当前真实 E2E 的已知限制。这里的限制不会在本轮文档整理中通过修改代码解决。

## Meso4

- 状态：`REAL_BUT_LIMITED`。
- 输出是未经校准的 fake-class 风险信号，不是媒体伪造概率、真实性概率或单一真伪结论。
- 在获授权 Celeb-DF v2 官方 518 视频上的冻结结果为 TN=1、FP=177、FN=1、TP=339，ROC-AUC `0.513648`；模型几乎全部预测为 fake。
- Accuracy 接近“始终预测 fake”的类别基准，不能宣传为可靠的通用深伪检测器。
- 当前采样轨迹只是视觉帧序列，不是人脸身份跟踪；没有热力图工件。
- 当前没有 active 校准器；阶段 6 的 `rejected` 校准器禁止加载。

## Whisper ASR

- 状态：`REAL_BUT_LIMITED`。
- 当前使用独立 8003 Worker 和本地 Whisper 模型执行 CPU 推理，依赖预置缓存，运行时不自动下载。
- Worker 默认硬超时 60 秒，Main 外层默认 70 秒。较长音频、低性能 CPU 或首次模型加载可能超时。
- 转写受噪声、口音、语速、重叠说话、音乐和压缩影响。
- 当前真实 smoke 只证明集成可运行，不构成准确率、实时性或通用性能声明。

## Tesseract OCR

- 状态：`REAL_BUT_LIMITED`。
- OCR 依赖本机 Tesseract、语言数据和抽帧结果；不是对视频所有帧执行完整文字识别。
- 小字号、低对比度、运动模糊、倾斜、遮挡、特殊字体、竖排和语言不匹配会导致漏识别或误识别。
- OCR 文本是待审计输入，不自动等同于视频中的真实事实。

## Claim Extraction

- 状态：`REAL_BUT_LIMITED`。
- 只从状态可用且带时间位置的 ASR/OCR 文本提取主张；没有可定位文本时不会凭文件内容猜测语义。
- 规则化提取不能覆盖所有省略、指代、讽刺、复杂关系或跨段上下文。
- 主张的 `no_evidence` 表示没有合格引用，不等于主张为假。

## AST 音频反欺骗

- 状态：`UNAVAILABLE`。
- 当前演示环境的 AST 模型工件不完整，因此不能形成可用音频伪造结果。
- 接口、加载校验或历史 smoke 不等于当前演示中可用。
- 阶段 8 没有获授权的冻结音频标签 manifest，不能报告音频准确率、AUC、EER 或其他性能数字。

## Audio-Visual Sync

- 状态：`EXPERIMENTAL`。
- 当前实现是 Haar 单脸、下半脸运动与音频能量相关性的启发式筛查，不是 SyncNet、唇读或活跃说话人模型。
- 需要稳定单脸、足够分辨率、足够语音和有效样本；多脸、无脸、低清、短语音或无音频会返回不可用或不适用。
- 当前 `run-service.ps1` 设置 `ENABLE_SYNC=false`，比赛启动链默认不执行该模块。
- Celeb-DF v2 官方 518 视频均无音频，未完成真实 `completed` 可用性或性能验收。

## Tavily

- 状态：`REAL_BUT_LIMITED`。
- 只在已有报告的显式 `refresh-llm` 操作中调用；首次上传不联网检索。
- 依赖有效 Key、DNS、代理、供应商可用性和外部页面质量。
- 搜索结果必须通过 URL、域名、时间和逐字片段结构校验；被拒绝的结果不会成为证据。
- 搜索结果的存在不自动证明主张或来源可靠。

## DeepSeek

- 状态：`REAL_BUT_LIMITED`。
- 只接收有大小上限的结构化证据包，不接收原始视频、关键帧、本地路径或 API Key。
- 模型只能提供辅助研判，不能替代三轴原始状态、人工复核、法律判断或处置决策。
- 输出可能遗漏、误解或过度概括证据；后端只校验引用索引和归属，不能保证自然语言分析正确。
- 依赖外部服务、Key、网络和供应商行为，当前没有正式准确率或稳定性评测。

## Internet Verification

- 状态：`EXPERIMENTAL`。
- 只接受 DeepSeek 指向已保存非 Mock 引用的合法索引；不能利用模型记忆或未保存网页作为证据。
- `insufficient_evidence` 表示完成校验后证据不足；与 `network_error`、`not_configured` 不同。
- 没有获授权冻结事实核查标签集，因此不能报告事实核查性能数字。

## Source Reliability / Provenance

- 状态：`REAL_BUT_LIMITED`。
- 依赖用户上传时声明的公开 `source_url` 以及刷新时取得的检索记录。
- 系统不下载该 URL 指向的视频，也不能从本地媒体字节恢复首发账号、完整传播链、编辑历史或平台身份。
- 没有来源 URL或同域名合格证据时应为证据不足，不等于来源虚假。

## Aggregate Assessment

- 状态：`EXPERIMENTAL`。
- Aggregate 是固定政策映射和权重产生的复核风险指数，不是学习得到的联合模型、伪造概率或真实性概率。
- 默认权重、35/65 路由阈值和 0.65 最低覆盖率没有联合标注集性能背书。
- 当前 `CONTENT_RISK` 将 `no_evidence` 映射为 `0.80`。这会把“缺少合格证据”转换为较高内容风险，存在语义混淆；本轮只记录，不修改代码。
- 缺失维度、低覆盖率和不可用信号会影响是否能给出总体值；不得人为填入 0、50 或其他伪中性值。
- 输出固定 `automatic_action=none`、`truth_label=none`，必须结合各独立维度和原始证据人工复核。

## FFmpeg / FFprobe

- 媒体处理使用固定输入、协议、线程、输出和时间边界。单条命令的固定超时可能拒绝复杂但合法的媒体。
- POSIX 有额外资源限制；Windows 没有同等的 Job Object 隔离。
- 编解码器、损坏容器、超高复杂度、首帧延迟或本机 PATH 差异都可能导致失败。
- 超时、解码失败或工具缺失必须显示为失败或不可用，不能解释为低风险。

## Worker 生命周期

- `start-all.ps1` 为四个服务打开独立 PowerShell 窗口，只根据端口监听判断是否跳过启动。
- 当前没有统一 PID 文件、就绪等待、依赖顺序确认、自动重启、崩溃恢复或 `stop-all.ps1`。
- 端口被其他进程占用时，脚本可能错误地认为服务已运行；必须检查 `/health` 的服务身份。
- Worker 与 Main 的启动入口监听 `0.0.0.0`，当前只适合受控本机环境；不能据此声称公网安全。

## 数据、留存与便携性

- SQLite、上传媒体、派生物和模型缓存位于本机，不进入 Git；源码 checkpoint 不能单独恢复 Secret、模型和 runtime 数据。
- `.env` 含真实 Key，必须独立安全管理。
- 当前工作版本已在现有机器跑通，但尚未完成另一台电脑上的依赖、PATH、模型、Secret、网络和启动验收。
- 因此不能声称“项目解压后在任意电脑直接运行”。

## 评测边界

- 只有 Meso4 的 Celeb-DF v2 官方 518 视频冻结评测可报告实际模型指标，而且结果显示基线能力很弱。
- 音频、事实核查、融合、消融和鲁棒性均缺少获授权冻结标签 manifest，保持 `not_applicable`。
- Mock 夹具、无音频视频、接口测试和健康检查不能用于模型性能声明。
